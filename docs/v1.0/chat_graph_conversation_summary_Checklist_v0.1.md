# Chat Graph 对话总结功能开发 Checklist

> 对应文档：`chat_graph_conversation_summary_PRD_v0.1.md`  
> 版本：V0.1  
> 使用方式：按阶段完成并验收，不要求一次实现全部后续候选功能。

- [ ] 确认旧总结的版本保留策略
