# v1.0.0 实现状态

v1.0 在现有 Question Graph、引用感知节点、多厂商 AI、双浏览器和本地优先能力上加入“对话总结”主流程。

## v1.0 对话总结

- 三个入口共用配置和结果模型：ChatGPT 页内浮窗顶部、Side Panel 项目工具栏，以及完整图/浮窗图的“总结此节点”。首次默认“当前分支 + 通用复盘”，节点入口优先“当前节点及上下文”。
- 三种范围分别是当前节点到逻辑根的祖先路径、当前 `chatId` 页面可采集的全部消息，以及目标节点和直接父节点的完整 turn（更早祖先只使用已有问题/短 summary）。这里的分支是 Chat Graph 逻辑路径，不是 ChatGPT 原生替代分支。
- 范围预览展示消息数、节点数、是否跨逻辑分支、估算长度、处理策略和缺失来源。来源不完整时默认阻止完整生成，只有用户确认后才生成带缺失标记的部分结果。
- 总结目录包含 33 个模块和 5 个预设。结果支持结论状态、系统推断与用户编辑独立标记、证据抽屉与定位、标题/模块编辑、最多 20 次编辑撤销、复制、单模块重试、Markdown、上下文包、分支建议与保存到图。
- user / assistant 来源原文只在生成任务内存中存在；完成、取消或失败后释放。IndexedDB 保存结构化总结、版本、任务 metadata、消息定位和最长 240 字的证据摘录；JSON 备份只包含总结 artifact、版本、图关系、定位和短证据摘录，不包含任务或原文。
- 总结任务在界面关闭后继续。浏览器或 MV3 Worker 终止会使未完成任务进入“已中断”，且必须重新采集原文后重试；取消操作幂等，迟到响应不能覆盖取消状态或新版本。
- 短范围可一次生成；长对话按语言感知 token 估算分段、保留相邻两条消息上下文，事实只提取一次，再以最多 6 个模块分批生成。部分失败保留成功模块和缺失区间，超过 20 段时要求缩小范围。
- 总结在图中使用独立紫色文档 artifact 和虚线关系边，不伪装成 Question Node，不参与 Current、status、父节点推荐和原问题定位。分支建议先创建 `planned` 问题节点，实际发送相同规范化问题后才绑定真实消息。
- Dexie schema 为 v9，新增 `reviewDocuments`、`reviewVersions`、`reviewJobs`。JSON 备份 schema v3 保存总结 artifact、版本、图关系与短证据摘录，继续兼容导入 v1/v2 并重映射内部 ID。
- “AI 父节点推荐”开关仍只控制自动推荐；用户主动总结会单独校验当前 Provider、模型、Key 和 HTTPS 域名权限。项目不运营代理、账号、埋点或云同步。

## 延续的 v0.13 导航基线

当前实现已在 v0.5 Question Graph 导航核心上加入 V0.6 常驻浮窗：收起态、工作态、Enter 后即时 Current、Parent / Summary 异步状态、轻量候选确认、Manual Change Parent、Parent focus 导航、详情页入口、拖动与位置/模式记忆均已进入主流程。

v0.7–v0.8.1 进一步加入浮窗图视角、节点右键详情/状态/删除、一键建图、项目级消息去重，以及对 ChatGPT 虚拟化历史的完整捕获与旧问题定位。v0.9.0 将父节点推荐升级为多厂商配置，并将浮窗调整为 Current 优先布局、统一节点菜单、单行暂停提示和全项目节点图视角；图视角支持缩放、拖动与适应全部节点。浮窗数据操作现在由统一后台命令层直接返回最新状态，当前界面不再依赖广播刷新。

原问题定位以当前 ChatGPT 页面为边界：定位时先按消息 ID、Turn ID、锚点与文本指纹查找当前页面，即使早期根节点保存的会话标识已经变化，只要原问题仍在本页即可滚动并高亮。跨页面自动打开会话暂不属于 v0.13 范围。侧栏完整图与浮窗图视角均为首次单击设为 Current、再次单击确认定位原问题，右键可查看详情、标记状态或删除；侧栏搜索页签可检索当前项目的 question、summary 与引用信息。

v0.13.0 增加问题引用捕获：附件保存文件 metadata，图片保存受限本地缩略图，Assistant 引用保存短摘录；三者都保留消息定位信息。详情问题图显示引用计数，节点详情展示引用卡片，浮窗显示 Current 与紧凑图的引用计数。引用定位扩展到 Assistant 消息，侧栏搜索扩展到文件名、图片说明和回答摘录。完整附件、原图和完整 Assistant Answer 仍不保存。

节点状态与父子结构相互独立：所有新节点默认为待讨论，新增子节点、改 Parent、批量建图和删除重挂均不自动修改状态，已完结状态只由用户手动设置。

浮窗只承担项目、Current、父节点、摘要、全节点图视角与关键导航动作；侧栏默认以 Current + Parent 展示当前讨论，并保留待讨论列表和项目级节点管理。

v0.2–v0.4 的 Decision/OpenQuestion 知识库、Supabase 登录/云快照与同步队列仍未恢复。v1.0 的 Review Document 和按需上下文包是独立 artifact/导出能力，不会把历史知识库模型重新混入 Question Node。当前 JSON schema v3 备份 Question Graph、轻量引用、总结 artifact 和版本，但不包含完整来源、AI 设置或 API Key。

自动化检查覆盖既有图导航回归，以及总结范围/目录、结构化解析、证据白名单、分段策略、编辑版本、任务状态、artifact、planned 节点、迁移和备份往返。真实浏览器中的短对话、多分支、超长对话和证据跳转仍属于每次发布前的人工验收，不由本文件声称已经自动完成。
