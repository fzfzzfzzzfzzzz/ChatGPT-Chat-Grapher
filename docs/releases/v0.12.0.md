# Chat Graph v0.12.0 — Local JSON Backup

v0.12.0 将问题状态与父子结构完全解耦，聚焦 Current / Parent 工作流，并加入本地 JSON 数据备份、浮窗项目管理和更清晰的问题树布局。

## 主要变化

- 新节点统一保持“待讨论”，节点状态只由用户手动修改。
- 已完结节点仍可作为父节点，同时保留跨项目与循环关系保护。
- 侧栏聚焦展示 Current 与 Parent，摘要可独立折叠。
- 完整图与浮窗图共用树形森林布局。
- 浮窗项目菜单支持重命名，侧栏可重新打开页面浮窗。
- 全部项目、问题节点、待讨论候选与撤销事件可导出为带版本的 JSON；导入会创建新的项目副本。
- 原问题定位改为当前页面优先，修复会话标识变化后可见根节点无法定位的问题。
- 首次启用扩展时，即使 ChatGPT 页面早已打开，也可从侧栏直接打开页面浮窗，无需先刷新页面。

## 定位范围

本版本只承诺在当前打开的 ChatGPT 页面中定位原问题。跨页面自动打开或切换其他会话暂不属于 v0.12 范围。

## 安装

### Chrome

1. 下载 `chatgpt-discussion-map-0.12.0-chrome.zip`。
2. 解压到长期保留的目录。
3. 打开 `chrome://extensions/` 并启用开发者模式。
4. 选择“加载已解压的扩展程序”，打开解压目录。

### Firefox 临时安装

1. 下载并解压 `chatgpt-discussion-map-0.12.0-firefox.zip`。
2. 打开 `about:debugging#/runtime/this-firefox`。
3. 点击“临时载入附加组件”，选择解压目录中的 `manifest.json`。

## 数据与隐私

项目图和设置保存在浏览器本地。JSON 备份包含问题图与消息定位信息，不包含 AI 设置或 API Key。启用可选 AI 后，请求直接发送给用户选择的厂商。
