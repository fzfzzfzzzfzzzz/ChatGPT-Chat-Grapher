# Chat Graph v0.13.0 — 引用感知节点

v0.13.0 让问题图保留“这个问题引用了什么”的轻量上下文，同时维持本地优先和非完整聊天数据库的边界。

## 新增

- 捕获用户消息中的附件、图片和 Assistant 回答引用。
- 图节点显示附件、图片与回答引用数量。
- 节点详情展示文件信息、图片缩略图和回答短摘录。
- 点击引用可定位当前 ChatGPT 页面中的用户或 Assistant 原消息。
- 搜索支持附件名称、图片说明和回答摘录。
- JSON 备份 schema v2 保存引用数据并兼容 v1 导入。

## 数据边界

- 不保存附件正文。
- 不保存原始图片，只保存受限尺寸的本地缩略图。
- 不保存完整 Assistant 回答，只保存用户实际引用的短摘录。
- 引用数据默认不会发送给 AI Provider。

## 已知限制

- ChatGPT DOM 变化可能暂时影响引用识别。
- 只有当前打开的 ChatGPT 页面支持原文定位，不自动切换其他会话。
- 部分跨域或未完成加载的图片可能只有名称或说明，没有缩略图。
